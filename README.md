# WTJOpenSpecTest

A spec-driven rebuild of the Wrike → Jira migration tool (originally built for Ursa Major),
used as a testbed for the [OpenSpec](https://github.com/Fission-AI/OpenSpec) CLI workflow.

## Purpose

Rather than porting the existing implementation, this repo reconstructs the migration tool
from specifications: capabilities are defined as specs first, changes are proposed and
reviewed through the OpenSpec change workflow, and implementation follows the approved spec.

## Status

Bootstrapping — OpenSpec not yet initialized.
